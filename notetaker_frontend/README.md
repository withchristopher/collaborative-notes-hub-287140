# Notetaker Frontend (Next.js)

This is the Next.js frontend for the self-hosted notetaking application.

Builds and runs independently. There are no references to any deprecated database visualizer paths or backend build dependencies.

## Commands

- npm run dev — start dev server on port 3000 (or NEXT_PUBLIC_PORT)
- npm run build — build the app
- npm start — start the production server

## Environment variables

See .env.example for configuration. Do not commit secrets directly to version control.
